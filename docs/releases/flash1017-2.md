# DeepSeek Flash1017: experimental oMLX runtime

An opt-in oMLX profile for the unchanged
[`DeepSeek-V4.1-Flash-1017-oQ2.5e-mtp` checkpoint](https://huggingface.co/mlx-community/DeepSeek-V4.1-Flash-1017-oQ2.5e-mtp/tree/78456115d301eecf9fadcdcc81c0cf6f8b2c8eab).
It combines BF16 vocabulary-weight reuse for verification rows 2–5, a bounded
512 MiB Engram row cache and 64 MiB Engram prefetch admission. Stock attention
arithmetic and native adaptive multi-token prediction are retained.

On one **256 GiB M5 Ultra Mac Studio**, this package measured **7.9% higher
generation throughput** across eight workloads against public oMLX `v0.7.1rc1`,
improving in all 16 workload/block pairs. Time to first visible text was
**4.5% lower**, with improvement in 11/16 pairs and noticeable block variation.
A separate quality comparison matched the baseline's **answer text and finish
reason on all 618 requests**, with zero task-score regressions.

These are observations from one machine, two timing blocks and fixed greedy
requests. They do not establish performance on other Macs, parity for every
prompt or sampling setting, or improvement over current upstream `main`.
The [research article and evidence](https://github.com/rubencu/flash1017-research/tree/v0.1.0)
include the raw data, standard coding-task grades, methods and offline analysis.

## Install

Requires **Apple Silicon, macOS 15+, CPython 3.12, at least 256 GiB unified
memory and 210 GiB available before loading**. The tested interpreter is
3.12.15. Obtain the complete pinned checkpoint separately; weights are not
included. Other hardware has not been evaluated.

Download the wheel, `flash1017-2-constraints.txt` and `SHA256SUMS` from this
release. In that directory:

```sh
shasum -a 256 --check SHA256SUMS
python3.12 -m venv .venv-flash1017
.venv-flash1017/bin/python -m pip install \
  --constraint flash1017-2-constraints.txt \
  ./omlx-0.7.1rc1+flash1017.2-cp312-cp312-macosx_15_0_arm64.whl
.venv-flash1017/bin/python -m pip check
.venv-flash1017/bin/omlx flash1017 --model /path/to/the/pinned/model --check
.venv-flash1017/bin/omlx flash1017 --model /path/to/the/pinned/model \
  --base-path ~/.omlx-flash1017 --port 8017
```

The [complete installation guide](https://github.com/rubencu/omlx/blob/v0.7.1rc1-flash1017.2/docs/flash1017-install.md)
covers download verification, configuration, authentication and source builds.
The wheel installs the server and web UI. It does not replace the macOS app.
The profile allows one active request and 131,072 tokens including output.
Fresh setup uses temperature 1.0; measured requests explicitly used temperature
0. The constraints reproduce recorded package versions, not a hash-locked
archive of every dependency artifact.
